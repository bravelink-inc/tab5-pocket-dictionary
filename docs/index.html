M5Stack Tab5 電子辞書　書き込みページ

書籍『M5Stack Tab5 で作る、自分だけの電子辞書』のファームウェア（版 v1.0-rc1）

はじめに

このページは、パソコンの Google Chrome か Microsoft Edge で開いてください（Safari・Firefox・スマートフォンでは使えません）。書き込むと、Tab5 に入っている元のデモアプリは消えます。

手順

  1. Tab5 の電源を入れ、USB-C ケーブルでパソコンにつなぎます（充電専用のケーブルは使えません）。
  2. 下の「Tab5 に書き込む」ボタンを押します。
  3. 一覧から USB JTAG/serial debug unit（Windows では「USB シリアル デバイス (COMx)」）を選んで「接続」を押します。
  4. 「Install」を押すと書き込みが始まります。1〜2 分かかるので、終わるまでケーブルを抜かないでください。
  5. 終わると Tab5 が再起動し、辞書の画面が出ます。
このブラウザは対応していません。パソコンの Chrome か Edge で開いてください。 この画面は https で開く必要があります。

書き込みの部品を読み込めませんでした。ページを再読み込みするか、パソコンの Chrome / Edge で開き直してください。

書き込むもの: ファームウェア本体と、内蔵の英和辞書（約 4.6 万語）

和英・漢字・国語辞典とテストのデータを足す（microSD カード）

和英・英和（逆引き）・漢字・国語の 4 冊と、テストの「基礎・標準・発展」「漢字の読み」のデータは、辞書を作るのページで、公式サイトのデータから自分のパソコンの中で作り、microSD カード（32 GB 以下、FAT32）に入れます。カードを Tab5 に挿して電源を入れ直すと、辞書が 5 冊になります（起動に約 9 秒かかります）。

うまくいかないとき

症状対処
一覧に何も出ないケーブルをデータ通信対応のものに替える。Tab5 の電源が入っているか確認する。
接続に失敗するほかのアプリ（Arduino IDE など）がポートを使っていないか確認し、Tab5 をつなぎ直す。
一覧には出るのに「Failed to initialize」と出るケーブルを別のものに替えるか、パソコンの別の差し込み口（USB ハブ経由も含む）につなぎ直して、もう一度ボタンから書き込む。一覧に名前が出るケーブルでも、書き込みのやりとりができないことがある。メッセージにある BOOT ボタンは Tab5 にはない。
途中で止まったもう一度ボタンから書き込み直す。何度でもやり直せます。
ボタンで書き込めない復旧用の 1 ファイル版ファームウェアをダウンロードし、Espressif 公式の書き込みツール（esptool-js）でアドレス 0x0 に書き込む。画面の向きと、SD カードなしで本体に保存した単語帳は初期化されます。

書き込みには ESPHome プロジェクトの ESP Web Tools（Apache-2.0）を使っています。ソースコードと手順は GitHub にあります。
