# 書き込みページの候補版 v1.0-rc3

このフォルダは、公開用ソース `7d663c5c8bf8b9f760f7f822cc6937c31bcf4b71` から生成しました。使用した部品、ビルド元、各パーツのハッシュは [build-info.json](build-info.json) にあります。完成版のタグ `v1.0` は、実機と読者の手順を確認してから確定します。

- 辞書検索と Enter による単語帳の手動登録に機能を整理しました。出題・採点機能と専用データの生成は含みません。
- 通常のボタンによる書き込みは、設定と本体の単語帳を保存する NVS 領域を上書きしません。旧1列・2列の単語帳を読み込み、次の保存では1行1見出しの形式になります。更新前に SD の `wordbook.txt` をパソコンにもコピーしてください。
- `tab5-pocket-dictionary-v1.0-rc3-firmware.bin` は 0x0 から書く復旧用です。NVS の設定と単語帳を初期化します。SD 上の `wordbook.txt` は消しません。
- 辞書4冊と出典文書は、`make-dict.html` で公式の元データ4ファイルから利用者が作ります。この候補版にはそれらの変換済みデータを含めません。
- 既存カードに残る旧出題データは使いません。更新時に利用者のカードから自動削除することもありません。

ESP-IDF 5.5.5 のビルドと、旧単語帳の読み込み・保存失敗時の保護・削除後に残すキー操作を含むホスト回帰テスト14件が成功しました。ブラウザの Worker/Pyodide でも元データ4ファイルから4辞書と出典文書を生成できることを確認しました。実機の画面・SD保存・電源・更新と復旧、Windows の手順、実際の SD カード選択と書き込みは未確認です。`device_tested` は `false` のままです。

過去の試作版のタグと履歴は保持しています。旧試作版のデータと、この候補版の手順を混ぜないでください。
