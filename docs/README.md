# 書き込みページの候補版 v1.0-rc1

このフォルダは、公開用のソース `bcf9e5669570ecfc8b129d4fc36165179e62e207` から作った候補版です。使用した部品と各パーツのハッシュは [build-info.json](build-info.json) にあります。完成版のタグ `v1.0` は、実機と読者の手順を確認してから確定します。

- 通常のボタンによる書き込みは、設定と本体の単語帳を保存するNVS領域を上書きしません。
- `tab5-pocket-dictionary-v1.0-rc1-firmware.bin` は0x0から書く復旧用です。NVSの設定と単語帳を初期化します。SD上の `wordbook.txt` は消しません。
- 辞書4冊・テスト2ファイル・出典文書は、`make-dict.html` で公式の元データから利用者が作ります。この候補版にはそれらの変換済みデータを含めません。

ビルド、ブラウザ変換とZIP保存、生成結果の一致、配布物の内部リンクと書き込み範囲を確認しています。実機でのSD読み込み・出典画面・日本語ファイル名の転送・更新、Windowsの手順、実際のSDカード選択と書き込みは未確認です。

過去の試作版のタグと履歴は保持しています。旧試作版のデータと、この候補版の手順を混ぜないでください。
